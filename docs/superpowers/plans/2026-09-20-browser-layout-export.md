# 浏览体验、迅雷导出与双包发布

用户已通过异步问题确认全部方案：网页高度可拖动、独立浏览窗口、同时提供内置与不含 .NET 两种 EXE、恢复确定直链的迅雷导出。

- 网页与资源区放在同一可调整网格，水平分隔条上下拖动，各区有最小高度。
- 独立浏览复用同一个 WebView2 控件和普通权限进程，不另起用户数据目录；关闭弹窗放回原窗口，主窗口关闭时安全清理。原资源捕获和登录状态持续有效。
- 导出操作只针对可见勾选资源；只允许已验证无需 Cookie/认证、响应确为图片或普通视频的地址；播放清单、页面地址、需登录链接跳过并提示。TXT 每行一个原始地址供迅雷导入，不自动启动外部程序，不包含 Cookie/请求头。
- 抖音当前只有兜底提示，尚缺测试链接及操作步骤。检查异常链并增加安全诊断分类；不能据此宣称 DRM，也不能声称抖音修复。
- 回归：分隔条、弹出返回、导出过滤单测和浏览器实测；安全全套测试；两套新目录发布，不覆盖旧的运行包。
