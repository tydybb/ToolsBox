# 文件解锁工具设计

## 目标

在 ToolsBox 中增加“文件解锁”工具。用户可输入、浏览或拖入文件/文件夹，扫描占用该路径的进程，并选择安全结束进程或高级强制关闭单个句柄。

## 功能范围

- 支持文件和文件夹路径；拖放后自动识别并立即扫描。
- 文件夹匹配其自身及全部子目录和文件，不遍历目录树。
- 显示占用路径、进程名、PID、进程路径、句柄值和权限状态。
- 支持多选后结束占用进程，操作前二次确认。
- 支持高级强制关闭所选句柄，默认折叠并进行更强警告。
- 权限不足时通过 UAC 按需启动同一程序的后台动作模式。
- 操作后重新扫描；只有目标占用消失才报告解除成功。

## 安全边界

- 不允许结束或关闭 ToolsBox 自身、PID 0、PID 4，以及关键 Windows 系统进程的句柄。
- 高级动作在执行前重新验证 PID、进程启动时间、句柄值和实际文件路径，避免句柄复用造成误操作。
- 所有动作逐项返回结果；部分成功不会显示为全部成功。
- 取消 UAC、进程退出、访问拒绝和路径不存在均显示明确提示。

## 架构

- `ToolsBox.Core/FileUnlocking`：路径规范化、目录边界匹配、模型、安全策略和操作结果。
- `ToolsBox.Windows/FileUnlocking`：系统句柄枚举、文件句柄路径解析、关闭句柄、结束进程和 UAC 调度。
- `ToolsBox.App/FileUnlocking`：路径输入、浏览、拖放、结果选择、确认对话框和刷新状态。

扫描使用 `NtQuerySystemInformation(SystemExtendedHandleInformation)` 获取系统句柄，并通过 `DuplicateHandle` 与 `GetFinalPathNameByHandle` 解析文件路径。高级关闭使用 `DUPLICATE_CLOSE_SOURCE`，但仅在重新验证目标后执行。

## 验证

- 单元测试覆盖路径规范化、文件与文件夹匹配、安全限制和过期请求验证。
- Windows 集成测试使用临时文件保持打开句柄，验证扫描能够发现占用。
- Release 全量测试、零警告构建和应用启动检查必须通过。
