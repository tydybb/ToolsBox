# 网页资源下载设计

## 2026-09-20 用户确认的交互修订（覆盖下文旧入口描述）

- 移除复制链接与导出 TXT。
- 统一为“环境检测”窗口，列出浏览器和视频组件组状态，确认后安装缺失项，展示真实下载百分比与校验/安装阶段；已安装完整组件跳过，损坏视频组件组整体修复。
- 资源复选框多选，表头三态全选；全选/取消及下载只针对当前筛选，隐藏项保留选择但不加入本次下载。
- 类型筛选单行居中；首页网页资源入口复用其他工具的导航样式与互斥选中效果。网页仍在普通权限独立窗口运行。

## 已确认的范围

- 在宝哥工具箱新增“网页资源下载”入口，沿用 main 分支，不改变其他工具行为。
- 内置浏览器供用户输入网址、自行登录、播放及滚动；仅发现当前页面及其加载的资源，不爬取关联页面或全站。
- 图片预览、类型筛选、多选、批量下载；视频默认最高可用清晰度，可手动选择。
- 结合浏览器资源发现和网站解析器，处理完整视频直链、HLS、DASH 及音视频分离。其他协议仅在引擎支持时处理，不能承诺所有网站可下载。
- 最终优先生成 MP4；优先无损封装或合并，不兼容时才转码。不可将播放清单改扩展名伪装成视频。
- 不绕过 DRM、验证码、付费权限或账号访问限制。识别到不支持的资源明确说明原因。
- 复制单条地址、批量复制、导出 UTF-8 TXT；不导出 Cookie、Authorization 等请求头。签名 URL 本身可能敏感，导出前提示勿公开分享。
- 引擎首次使用经确认下载；同时提供手动选择组件目录，不需要用户自建下载服务器。

## 界面与操作

工具页面分为浏览控制、资源列表、下载任务三个部分。地址栏提供前进、后退、刷新及开始/停止识别。导航后资源按页面分组，已排队任务不删除；停止识别不取消下载。

资源行显示类型、名称、缩略图、已知清晰度、格式、大小（未知则明确显示未知）和来源域名。原始签名地址不用于日志。流的分段请求不得逐个成为视频行；通过清单或解析器结果归为完整资源。blob 地址不作为可直接导出的 HTTP 下载链接；不能还原来源时提示不支持。

用户明确选择保存目录后开始下载，批量任务默认最多两个同时下载、一个转码。任务显示排队、解析、下载、合并、转码、验证、完成、取消或失败；支持取消、失败重试、打开输出文件夹。不覆盖同名文件，自动追加序号。首版不承诺退出后续传，退出有活动任务时要求确认。

## 权限与进程边界

现有主程序保持管理员启动要求，但浏览器、解析器和媒体引擎必须在普通权限进程执行；无法建立普通权限工作进程时拒绝启动浏览功能，不回退到管理员浏览。

使用同一 EXE 的 --web-resources 模式启动独立 WebView2 浏览工作进程承载浏览及下载界面，由工具箱入口启动并跟踪；浏览器不运行在管理员 WPF 进程，复用现有单文件发布。用户已确认独立浏览窗口，避免跨权限嵌入窗口造成焦点及生命周期问题。主程序关闭前提醒任务将取消，工作窗口等待清理后退出，不结束无关进程。

工作进程使用独立用户数据目录，不自动读取系统浏览器账号或 Cookie。用户自行登录；提供清除网站数据入口。登录信息只用于目标站点的内置下载，不向无关域名转发；重定向必须重新判断凭据作用域。日志脱敏且不记录完整认证请求头。网页不得调用任意宿主命令或指定可执行文件。

## 组件供应与更新

组件管理区分别显示解析器、FFmpeg/ffprobe 和 WebView2 Runtime 的状态、版本和来源。首次下载必须展示组件清单、来源和已知体积并由用户确认；不在点击工具入口时静默安装。

解析器使用 yt-dlp 官方发布渠道；FFmpeg 使用项目下载页认可的 Windows 构建渠道，实施时锁定具体版本、架构、许可证及可信校验值。校验值必须来自受信发布元数据或随应用发布的清单，不能把任意用户提供的哈希当作可信证明。下载至临时位置，校验后原子启用；失败保留旧版本，不自动运行未校验文件。手动导入明确提示用户只选择可信来源，检查所需文件及版本。

WebView2 优先复用已安装运行环境；缺失时提供微软安装渠道及明确提示，不捆绑完整浏览器运行时。包大小必须在实际锁定组件后测量，不把先前预算当成交付体积。

## 下载与输出

网络与媒体工作均为异步且可取消。下载临时文件放在所选输出目录下的专用任务子目录；只有验证成功后才发布最终文件。路径名称清理非法字符和目录穿越，不信任远端文件名。取消只能停止本任务创建并持有的进程，不按进程名批量结束程序。

视频用 ffprobe 检查有效视频轨道、时长及预期音轨；有明确预期时长时检查明显截断。验证不是逐帧完好保证，不宣称绝对完整。图片检查内容格式，不把 HTML 错误页存成图片。网络过期、权限不足、空间不足、引擎缺失、DRM 和转码失败分别提示。有限次数重试不得无限循环。

## 文件与测试边界

- Core：资源类型、候选项去重、文件名安全、任务状态、导出规则。
- Windows：普通权限工作进程启动与生命周期；不扩大主程序的网页指令入口。
- App/WebResources：普通权限工作模式的 WebView2 窗口、资源发现、受限登录态及下载协调；MediaDownloads 独立项目负责组件和媒体处理。
- App：导航入口、工作进程启动状态及失败提示。
- Tests：伪造 HTTP 响应、离线网页及本地媒体样本；禁止以真实账号凭据作为测试数据。

验收包括：图片/直链下载、HLS 合并、DASH 音视频合成、必要转码、最高质量与手动选择、仅链接导出、签名过期提示、组件下载失败及手动导入、取消清理、同名不覆盖、浏览进程确为普通权限、退出清理，以及既有工具的安全筛选回归。真实网站覆盖需要另行逐站验证，不将离线测试等同于全网兼容。
