# 宝哥工具箱品牌调整设计

## 目标

将面向用户的应用名称统一为“宝哥工具箱”，并使用适合 Windows 任务栏和程序文件的锤子图标。

## 设计

- 图标采用蓝色圆角方形底板与居中的金黄色锤子，轻微立体高光，无文字、无水印。
- 保留透明画布边缘，确保 Windows 圆角缩放时不裁切主体。
- 从高分辨率 PNG 生成包含 16、32、48、64、128、256 像素层级的 `.ico`。
- 窗口标题、侧栏品牌、程序集标题、产品名和输出程序文件名统一为“宝哥工具箱”。
- 解决方案名、项目目录及 C# 命名空间继续使用 `ToolsBox`，避免无功能价值的代码重命名。

## 验证

- 检查 PNG 和 ICO 文件存在且 ICO 包含多尺寸图层。
- 执行 Release 全量测试和零警告构建。
- 确认输出为 `宝哥工具箱.exe`，并通过启动检查。
