# 宝哥工具箱网络流量监控与上传限速设计

## 目标

在现有 .NET 8 WPF 工具箱中增加“网络流量”工具，实时显示本机软件及其进程的 TCP/UDP 上传、下载速度与本次会话累计流量，并允许按可执行文件完整路径设置持久化的上传限速。

主程序继续以普通权限运行。用户主动开始网络监控或修改限速规则时，按需通过 UAC 启动管理员辅助进程。第一阶段不安装网络过滤驱动，不提供下载限速，但为后续双向限速保留接口边界。

## 已确认的产品边界

- 监控本机全部可观察到的 TCP/UDP 软件流量。
- 默认按可执行文件路径汇总，同一软件的多个 PID 合并为一行。
- 软件行可以展开查看各 PID 的实时数据。
- 显示实时上传/下载速度及本次监控累计流量。
- 统计只存在于当前监控会话，关闭工具箱后清零，不保存历史。
- 上传限速规则按可执行文件完整路径保存，软件重启后继续生效。
- 主程序不要求始终以管理员身份运行；进入监控或管理规则时按需弹出 UAC。
- 当前不实现下载限速、历史流量报表、远程地址分析、域名解析或网络内容检查。

## 技术方案

### 流量采集

管理员辅助进程启动 Windows ETW 内核 TCP/IP 网络跟踪，消费 TCP、UDP、IPv4 和 IPv6 的发送与接收数据事件。每条有效事件至少转换为以下内部增量：

- 进程 PID
- 流量方向：上传或下载
- 字节数
- 事件时间戳

只统计数据发送与接收事件，不把连接、断开等控制事件的结构大小计入流量。采集层不承担 UI 汇总逻辑。

辅助进程以固定间隔批量发送增量，避免为每个数据包进行一次跨进程调用。主程序按一秒窗口计算当前速度，并累加本次会话总量。

### 进程身份与软件汇总

进程身份使用 `(PID, StartTime)`，避免 PID 被操作系统复用后把两个进程的数据合并。平台层尽力读取：

- 进程名称
- 可执行文件完整路径
- 文件图标
- 启动时间

可读取完整路径时，以规范化后的、不区分大小写的路径作为软件汇总键。路径不可读取时，使用受限的进程身份分组，允许显示统计但不允许创建限速规则。

进程退出后保留其本次会话累计值，实时速度逐步归零；软件汇总行仍展示会话累计流量。相同路径的新进程会加入原软件汇总。

### 上传限速

管理员辅助进程通过 Windows `NetQosPolicy` 管理 QoS 策略：

- 匹配条件为规范化后的可执行文件完整路径。
- 协议条件同时覆盖 TCP 和 UDP。
- 网络配置文件覆盖所有网络类型。
- 限速值统一转换为每秒比特数后提交。
- 不使用 `ActiveStore`，使规则在重启后仍然存在。

规则名采用 `BaoGeToolsBox-<路径哈希>`，并附带能够识别为本工具创建的固定前缀。工具只能修改或删除此前缀且路径匹配的规则，不能操作其他系统、域策略或用户创建的 QoS 规则。

如果检测到更高优先级或同一程序的外部 QoS 策略，界面显示冲突并拒绝静默覆盖。路径已经不存在的本工具规则显示为失效规则，允许用户手动删除。

限速抽象使用方向字段和能力查询。第一阶段实现只声明 `Upload` 能力，后续网络驱动可以增加 `Download`，不需要修改 ViewModel 的基本规则模型。

## 项目结构

### ToolsBox.Core

新增独立的 `NetworkTraffic` 领域：

- 流量增量、进程身份、进程统计和软件汇总模型。
- `INetworkTrafficSource`：开始、停止及读取流量增量。
- `IBandwidthLimitService`：读取能力、查询、设置和删除限速规则。
- 会话聚合器：按一秒采样窗口计算速率和累计值。
- 搜索、排序与活动流量过滤逻辑。

领域层不依赖 WPF、ETW、进程 API、PowerShell 或管理员权限。

### ToolsBox.Windows

新增平台实现：

- ETW 网络事件采集与事件字段适配。
- 进程元数据和软件图标读取。
- Windows QoS 查询与管理。
- 提权辅助进程的请求验证、生命周期和命名管道通信。

外部命令调用必须使用固定命令模板、严格数值校验和安全路径转义；不允许把未经处理的界面文本拼接成 PowerShell 脚本。

### ToolsBox.App

新增：

- `NetworkTrafficViewModel`
- `NetworkTrafficView`
- 软件汇总行和 PID 子项的展示模型
- 限速编辑对话框
- 左侧“网络流量”导航项及对应 DataTemplate

`MainViewModel` 负责持有该工具，并在应用关闭时统一释放监控会话和通信资源。

## 提权辅助进程与 IPC

沿用单一可执行文件的辅助模式，增加专用启动参数，不新增常驻 Windows 服务。

1. 主程序创建只允许当前用户访问的命名管道，并生成一次性随机令牌。
2. 使用 `runas` 启动同一可执行文件的管理员辅助模式。
3. 辅助进程连接管道后必须先提交令牌，验证通过才能启动 ETW 或执行 QoS 操作。
4. 消息采用带版本号和类型字段的长度前缀 JSON，区分握手、流量批次、状态、规则命令、结果和停止消息。
5. 主程序关闭、管道断开或收到停止消息后，辅助进程停止 ETW、释放资源并退出。

单次辅助进程同时承担本次网络监控和 QoS 管理，避免每次修改规则重复弹出 UAC。若用户只管理已有规则而尚未开始监控，也可以按需启动辅助进程。

## 界面设计

### 顶部工具栏

- “开始监控”或“停止监控”按钮。
- 软件名称、路径或 PID 搜索框。
- “仅显示有流量的软件”开关。
- 监控状态、最近采样时间和错误提示。

### 软件列表

默认按当前上传与下载速度之和降序排列。每个软件显示：

- 图标、软件名和路径
- 当前上传速度和下载速度
- 本次累计上传和累计下载
- 当前包含的进程数量
- 上传限速状态
- 可展开的 PID 列表

PID 子项显示 PID、进程名称、启动时间、实时速度及累计流量。

### 限速编辑

可选择 128 KB/s、512 KB/s、1 MB/s、5 MB/s，或输入正数并选择 KB/s、MB/s 单位。“不限速”删除本工具对该路径创建的规则。

路径不可读取、程序路径不存在或策略存在外部冲突时禁用设置操作，并给出具体原因。页面始终显示“当前只限制上传速度”。

## 生命周期与状态

- 打开页面不会自动弹 UAC，只有点击开始监控或执行限速管理时才请求权限。
- 用户取消 UAC 后保持未启动状态，其他工具继续正常工作。
- 一旦授权成功，辅助进程在本次主程序运行期间保持空闲待命，避免每次修改规则重复弹出 UAC；停止监控只停止 ETW 会话，不立即结束辅助进程。
- 切换到其他工具时监控继续；点击停止或关闭应用才结束会话。
- 停止后保留本次会话数据显示，重新开始时创建新的空会话。
- 辅助进程崩溃或管道断开时停止计速，保留最后数据并显示重新启动入口。
- 只清理由本次辅助进程创建且身份可验证的 ETW 会话，不停止第三方诊断会话。
- 应用正常退出和异常断线路径都必须释放 ETW 会话、管道、取消令牌和辅助进程。

## 错误处理

- ETW 启动失败：显示系统错误和重试入口，不伪造空监控结果。
- 进程在元数据读取前退出：保留 PID 和已统计字节，名称显示“进程已退出”。
- 受保护进程：显示可获得的统计信息，路径和限速能力标记为不可用。
- QoS 创建、修改或删除失败：读取系统命令错误，返回可理解的中文提示，并重新查询真实规则状态。
- IPC 消息损坏、版本不兼容或令牌错误：立即断开，不执行管理员操作。
- 超大事件速率：使用有界批次队列；队列发生丢弃时显示“统计可能不完整”，不能静默忽略。

## 性能约束

- ETW 消费和进程元数据读取不在 UI 线程执行。
- 流量事件先按进程和方向累加，再批量发送给主程序。
- UI 最多每秒刷新一次可观察集合，避免每包刷新。
- 进程路径、名称和图标按 `(PID, StartTime)` 缓存，进程退出后定期回收。
- 聚合与 IPC 队列必须有界；高流量情况下优先保证 UI 响应并报告统计降级。

## 测试策略

### 自动测试

- 多 PID 按路径汇总及路径大小写归一化。
- 一秒窗口速度、会话累计、停止与重新开始。
- PID 重用、进程退出和路径不可访问。
- 搜索、排序及活动流量过滤。
- KB/s、MB/s 到比特每秒的转换与非法值拒绝。
- QoS 规则命名、所有权校验、冲突检测和删除保护。
- PowerShell 参数与路径转义，防止命令注入。
- IPC 握手令牌、消息版本、序列化、取消与断线。
- 使用模拟流量源验证 ViewModel 刷新及错误状态。

### Windows 实机验收

1. 点击开始监控，仅出现一次 UAC。
2. 使用多个程序产生 TCP、UDP、IPv4 和 IPv6 流量。
3. 验证软件汇总与 PID 子项累计值一致。
4. 验证停止监控后速度归零且累计值保留。
5. 创建临时上传限速，通过系统 QoS 查询确认规则和路径。
6. 产生可测量的上传流量，确认实际速度受限。
7. 解除限速并确认临时规则被删除。
8. 关闭工具箱，确认辅助进程和本工具 ETW 会话均退出。
9. 执行完整 Release 构建和全部自动测试。

实机测试创建的规则必须在 `finally` 清理；如果清理失败，要报告具体规则名供人工处理。

## 完成标准

- 用户可以查看按软件汇总并可展开到 PID 的实时上传、下载速度及会话累计流量。
- UAC 仅在需要管理员功能时出现，主程序保持普通权限。
- 用户可以按完整程序路径创建、修改和删除持久化上传限速。
- 系统进程、权限失败、策略冲突、辅助进程退出及高流量降级都有明确状态。
- 关闭应用不残留辅助进程或本工具的活动 ETW 会话。
- 自动测试、Release 构建和约定的 Windows 实机验收全部通过。
