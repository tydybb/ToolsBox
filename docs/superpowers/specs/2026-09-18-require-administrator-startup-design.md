# 宝哥工具箱启动即管理员权限设计

## 目标

宝哥工具箱每次启动时都由 Windows 请求管理员权限。无论从 Visual Studio、资源管理器、快捷方式还是发布后的可执行文件启动，都必须先通过 UAC，授权成功后才创建主窗口。

## 已选方案

采用 Windows 应用清单的 `requestedExecutionLevel level="requireAdministrator"`。在 `ToolsBox.App` 项目中显式指定该清单，使生成的 Debug、Release 和发布版可执行文件使用相同执行级别。

未选择的方案：

- 普通权限启动后再用 `runas` 自我重启：会产生短暂双进程和额外生命周期分支。
- 保持网络监控与文件解锁按需提权：不符合用户“启动就要管理员权限”的确认要求。

## 兼容性与边界

- 保留现有网络监控和文件解锁辅助进程协议及命令行入口，不在本次变更中重构业务逻辑。
- 主程序已经提权时，`runas` 启动同一程序的辅助模式不会再次显示新的 UAC 确认，但仍保持现有 IPC 隔离。
- 用户拒绝 UAC 时，应用不启动，这是预期行为。
- README 改为明确说明应用启动即需要管理员授权。

## 验证

- 增加配置测试，读取应用清单并断言执行级别为 `requireAdministrator`。
- 验证测试先在缺少清单时失败，再添加清单和项目引用使其通过。
- 执行 Debug、Release 构建和完整自动测试。
- 检查生成的可执行文件包含管理员执行级别；UAC 安全界面由用户手动确认，不进行自动化点击。
