# 宝哥工具箱 v2026.10.22.1

首次整理开源 Release，面向 Windows 10/11 x64。

## 本次内容

- 打卡检查改为短暂普通权限读取进程：SQLite 初始化失败不会持续影响常驻提醒，下次检查可重试，无需每天更换或重开 EXE。
- 缓存内嵌 SQLite 原生组件，缺失或损坏时校验恢复；兼容当前有效已提交的日志帧，保留同账号当天已确认时间，读取失败不等于未打卡。
- 汇总界面、主题、提醒、计时日历、双色球及打卡回归测试。
- 增加 GPL-3.0-only、贡献 / 安全指南、Issue / PR 模板、第三方声明、Windows CI 和版本标签发布流水线。
- 未授权角色 PNG 不随当前源码快照与发布包分发，改用代码绘制的原创几何搭子；计时及互动保留。既有 Git 历史未重写，不代表角色官方授权。

## 选择下载

- `ToolsBox-2026.10.22.1-win-x64-self-contained.zip`：内置 .NET，推荐普通用户选择。
- `ToolsBox-2026.10.22.1-win-x64-framework-dependent.zip`：不内置 .NET，需要 [.NET 8 Desktop Runtime x64](https://dotnet.microsoft.com/zh-cn/download/dotnet/8.0)。
- 同名独立 `.exe` 功能相同；ZIP 额外包含许可证与第三方声明，再分发时须一起保留。
- 两种版本均不捆绑完整 WebView2 Runtime、yt-dlp、FFmpeg；网页工具提供环境检测与按需安装。
- 核对 `SHA256SUMS.txt`：`Get-FileHash .\下载的文件 -Algorithm SHA256`。当前 EXE 未做商业代码签名，校验值不是发布者证书。

## 升级与边界

从托盘正常退出旧版“整个工具箱（含打卡提醒）”，再替换并启动新 EXE。首次升级需要退出一次；不要删除用户本地配置目录，启用登录自启时保持 EXE 路径固定。主窗口仍请求管理员权限，网页和打卡读取保留普通权限隔离。

自动测试使用合成数据，排除实际关闭句柄的危险测试及独立实机 Probe。模拟跨日恢复不等于已实机连续运行多日；真实钉钉版本、Windows 登录 / 锁屏 / 休眠和网站播放器兼容性需按环境验证。节假日日历目前仅内置 2026 年。网页下载不保证所有站点，不支持绕过 DRM、付费或登录权限。
