# 宝哥工具箱

面向 Windows 的可扩展桌面工具箱，基于 .NET 8 和 WPF。包含端口监控、文件解除占用、网络流量、下班倒计时和网页资源下载。

## 网页资源下载

点击左侧“网页资源下载”打开独立普通权限窗口。主工具箱仍要求管理员权限，但网页、视频解析器和转码组件不以管理员身份运行；无法安全启动时拒绝打开浏览器。

1. 输入 HTTP(S) 网页地址，在工具内自行登录、播放视频或滚动页面；“持续识别”只收集当前页面加载的资源，不爬取全站。
2. 勾选图片或视频，支持逐项多选和表头全选。全选、取消选择及下载仅作用于当前筛选结果；隐藏项保留勾选但不加入本次下载。对复杂网页可点击“解析当前页面视频”；高亮一个视频后可点击“读取所选视频清晰度”。默认最高可用，也可手动选择解析出的格式。
3. 选择保存目录并下载。视频会下载后封装为 MP4，封装失败再尝试转码；支持引擎能够处理的直链、HLS、DASH 和音视频分离，不将播放清单改名冒充 MP4。
4. 任务列表显示阶段、可用的下载进度和速度，可取消、重试及打开文件夹。最多同时下载两个任务，媒体转换串行执行；同名自动编号，不覆盖已有文件。关闭窗口会取消任务并等待清理，不保证重启续传。

图片当前支持 PNG、JPEG、GIF、静态 WebP 的下载与结构校验，部分其他格式可能被识别但不能下载；不会把 HTML 错误页存成图片。视频发布前检查 MP4 容器、有效时长和应有音轨；这不是逐帧完整性保证。

播放器左上方在完整媒体已可靠绑定后才启用“↓ 下载此视频”；尚未播放或未识别成功的卡片显示禁用的“请先播放 / 待识别”，不是可下载承诺。先播放目标视频，按钮可用后点击，在工具箱原生确认框中核对视频、来源、清晰度和保存目录后下载；已识别的视频暂停后仍可下载。网页消息本身不能启动下载或读取下载 Cookie；切换页面、播放器源或 iframe 后，旧确认会失效。多个可识别播放器可通过“解析当前页面视频”选择；不把预加载的下一条当作当前视频。

悬浮下载按钮放在原播放器容器内，移到按钮时保留视频卡片的鼠标悬浮状态，不模拟鼠标事件或强制播放。按钮随容器滚动、平移和正向缩放定位；旋转、倾斜、镜像或 3D 变换容器暂不显示悬浮按钮，已识别的资源仍可从列表操作。

可靠绑定的当前视频也会自动进入资源列表，显示视频标题及来源类型，无需先点击悬浮按钮。重复识别不会改变已有行的位置和勾选状态；播放器切换后旧选择不会继承给新视频，下载前再次核对来源。清空列表会抑制当前已清空的来源，切换视频或重新导航后可继续识别，也可通过悬浮按钮明确重新添加。自动识别不会自动下载或读取下载 Cookie。

切换网页、刷新、前进后退和站内地址变化时，资源列表及勾选状态会自动重置，仅重新展示当前页面识别到的资源；下载任务、收藏、历史和登录状态保留。跳转前发出、跳转后才返回的请求不会混入新页面。同一 URL 跨页面并发请求无法确定归属时会保守跳过；异常未完成请求记录超过安全上限时会提示重新打开网页资源窗口。浏览器缓存视频可凭已观察的来源重新绑定当前可见播放器，不把旧列表搬到新页面。

抖音优先使用当前播放器真实加载的完整媒体；对 blob 播放器，仅在当前文档正常收到的视频元数据与播放器视频编号、时长一致时绑定，不猜测最近的网络请求。识别范围包含推荐页的 `module/feed` 元数据；同一文档内滚轮/上下键切换时，在途预加载响应可以继续补充有限的媒体目录，但必须重新绑定当前可见视频才进入资源列表，不恢复旧地址的资源行。真实网页跳转仍会丢弃旧文档的在途响应。未绑定时可从明确的单视频详情/分享地址尝试引擎解析；首页不能确定单条视频时会提示。关闭网站可关闭的登录提示或自行完成登录后再操作，不绕过访问限制。并非所有 blob、直播、DRM、iframe 或直接 video 元素全屏都能放置按钮或下载。

B 站番剧页会将可见播放器绑定到明确的当前单集 `ep` 地址，列表标记“当前单集·下载时解析并合并音视频”；下载仍经过视频组件，输出带声音的 MP4，不把 `.m4s` 音视频片段当成完整视频。不能确定当前集、多个播放器有歧义或检测到受保护媒体时不会猜测下载；番剧合集 `ss` 页面不回退为整季下载。单集解析时长必须与当前播放器相符，下载后再次检查输出时长及音轨。

网页与资源列表之间的横向分隔条可上下拖动。“独立浏览 ↗”会将同一个浏览器放到独立窗口，继续识别资源并共用登录状态；关闭独立窗口后网页放回工具窗口。

B 站等网站由用户点击触发的“新窗口打开”链接，会在当前工具网页中跳转，继续使用原登录环境，也可后退；网站自动弹窗及非 HTTP(S) 协议仍拦截。该实现使用 WebView2 的用户手势标志与当前文档校验，参见[微软新窗口事件说明](https://learn.microsoft.com/en-us/microsoft-edge/webview2/reference/winrt/microsoft_web_webview2_core/corewebview2newwindowrequestedeventargs)。

2026-09-20 实测：B 站点击视频可在原窗口打开并后退；用户提供的抖音视频 `7680095187900697907` 已保存为 1080p、H264/AAC、438.9 秒的有效 MP4。具体证据和未覆盖边界见[播放器下载验收记录](docs/superpowers/2026-09-20-player-media-verification.md)，不代表全站支持保证。

同日补充实测：B 站用户提供的番剧 `ss33415` 当前第 1 集识别为 `ep323085`，从资源列表下载得到 1493.04 秒、AV1/AAC 双轨的有效 MP4。列表自动识别、过期来源拦截及清空行为见[资源列表与番剧修复验收记录](docs/superpowers/2026-09-20-resource-list-bangumi-verification.md)。会员权限、其他分集、站点后续更新和 DRM 不在此结果的保证范围。

抖音同清晰度、同码率的候选优先使用元数据已经提供的官方播放链接，保留其它 CDN 备选，避免优先选到拒绝访问的旧 CDN 地址。只调整已有来源顺序，不生成签名或绕过登录。连续滚轮/下键切换、按钮可用性与实际 MP4 下载的范围见[连续切换修复验收记录](docs/superpowers/2026-09-20-douyin-continuation-verification.md)。

当前仅提供内置资源下载，不再提供迅雷链接导出；资源多选、全选、视频解析和 MP4 下载仍保留。

### 收藏、历史与登录状态

- 顶部“☆ 收藏当前页”保存当前网页；“收藏夹”支持打开、重命名、删除，重复收藏同一地址不会新增重复条目。
- “历史记录”保存成功打开的网页，最近访问优先，同一地址去重，最多 500 条；支持打开、删除单条和清空。
- 收藏和工具历史列表保存到 `%LOCALAPPDATA%\ToolsBox\BrowserLibrary.json`，关闭软件后保留，仅存本机。地址可能带敏感查询参数，请勿分享该文件。文件无法读取时保留原文件并禁用修改，不影响网页浏览。
- 网站正常的持久 Cookie 和本地存储继续保存在原有 `%LOCALAPPDATA%\ToolsBox\WebProfile`，更新 EXE 或重启工具箱不会主动清除。**清空历史不会退出登录**；“清除网站数据”是独立操作，会明确提示退出登录。网站主动过期、撤销授权或仅提供会话级登录时，仍可能需要重新登录；本工具不延长 Cookie 有效期，也不保存账号密码。

保存机制依据：[WebView2 用户数据目录](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/user-data-folder)。

### 浏览器及视频组件

- 点击“环境检测”查看 Microsoft WebView2 Runtime 和视频解析/转码组件组的状态；检测本身不下载任何内容，点击安装后只处理缺失项。
- 下载阶段显示实际进度，校验、解压和安装显示阶段状态。WebView2 从微软下载并验证微软签名，以普通用户身份安装；视频组件 yt-dlp、FFmpeg、ffprobe 校验 SHA256 后启用，无需自建服务器。已有完整组件组不会重复下载。
- 自动下载失败时，可把可信来源的 `yt-dlp.exe`、`ffmpeg.exe`、`ffprobe.exe` 放在同一目录，在环境窗口使用“导入组件目录”。导入会执行版本检查，请勿选择不可信程序。安装器运行期间需等待结束，避免中断安装。
- 组件存于 `%LOCALAPPDATA%\ToolsBox\MediaComponents`；工具内网站数据存于 `%LOCALAPPDATA%\ToolsBox\WebProfile`，与系统浏览器独立，可在窗口清除。内置下载使用按域限制的登录 Cookie；视频引擎所需临时 Cookie 文件限制当前用户访问并在操作结束后清理。
- 不绕过 DRM、验证码和网站访问权限。不存在“所有网站都能下载”的保证；站点更新、过期地址、缺少授权或引擎能力不足均可能失败。

单文件 EXE 不包含下载引擎和完整浏览器运行环境。真实站点支持情况需逐站验证；本地样例验收不能代替网站登录和播放器人工验收。

## 端口监控

- 读取 TCP、UDP、IPv4、IPv6 端口。
- 显示本地/远程地址与端口、TCP 状态、PID 和进程名。
- 可按端口、PID、进程名、协议、状态或地址搜索。
- 自动刷新频率可选 1、2、5、10 秒，默认 2 秒。
- 支持暂停/继续自动刷新以及立即刷新。
- 刷新失败时保留上一次有效结果。

程序直接调用 Windows IP Helper API，不解析 `netstat` 文本，也不会结束任何进程。普通权限通常足以获取端口和 PID；个别受保护或已退出进程的名称可能显示为“无法访问”或“进程已退出”。

## 文件解除占用

- 可输入完整路径、浏览选择文件/文件夹，或直接拖入单个文件/文件夹。
- 从普通资源管理器拖入管理员窗口时，使用 Windows 原生文件拖放接收路径；仅在“文件解除占用”页面空闲时接收，放下后自动扫描。一次仅接收一个路径，拖入不会自动结束进程或关闭句柄。
- 文件夹检测自动包含其自身以及全部子目录和文件，不需要遍历大目录。
- 文件路径查询在无窗口辅助进程中隔离执行，单个句柄查询超过 250 毫秒会跳过并提示结果可能不完整；扫描最长 30 秒，结束或失败后恢复检测按钮。已以管理员身份启动时，“管理员扫描”直接复用当前权限。
- 显示占用进程、PID、实际占用路径、句柄值、进程路径和权限状态。
- 选择列表头支持全选、取消全选和部分选中状态，覆盖全部当前结果；显示已选记录数及去重后的进程数。扫描或操作时禁用选择，新扫描清空旧选择。
- “强制结束所选进程”会先锁定勾选清单，逐项显示进程名、PID 和程序路径；确认窗口默认取消，必须勾选风险确认才能执行。只终止清单中通过身份校验的单个进程，不递归终止子进程。
- 资源管理器（explorer）、桌面窗口管理器和已知关键系统进程受保护；若选中受保护、缺少身份或身份冲突的记录，会阻止整批操作，提示取消勾选或重新扫描。保护名单不是所有系统进程的完整清单。
- 确认及执行期间不能重新扫描、改变路径或选择；修改路径会清空旧检测结果，避免误操作旧路径的进程。
- “高级危险操作”可以只关闭所选文件句柄，不结束进程。
- 宝哥工具箱启动时会统一请求管理员权限，文件解除占用操作直接使用已获得的系统权限。

> 请优先保存文件并正常关闭相关程序。强制结束进程仍可能丢失未保存数据，且该软件自身的关联窗口或服务可能随它退出；取消进程树终止并不代表零风险。强制关闭句柄也可能使目标程序崩溃、状态异常或损坏数据。ToolsBox 会在终止前复核 PID 和启动时间，关闭句柄前另核验句柄路径，但无法消除这些强制操作本身的风险。

## 网络流量

- 使用 Windows ETW 实时统计 TCP、UDP、IPv4 和 IPv6 的上传、下载流量。
- 默认按可执行文件路径汇总软件流量，可展开查看各个 PID 的实时速度和本次会话累计值。
- 采样只更新原位置的数据，不随瞬时网速重新排列；新软件追加到底部，保留选中行和展开详情。搜索或启用“仅显示有流量”时，列表仍会按筛选条件增减。
- 支持按软件名称、程序路径或 PID 搜索，也可以只显示当前有流量的软件。
- 可为能够读取完整路径的软件设置持久化上传限速，内置 128 KB/s、512 KB/s、1 MB/s 和 5 MB/s，也支持自定义值。
- 限速规则由 Windows QoS 提供，按可执行文件路径保存；软件或电脑重启后仍然生效，可在同一界面解除。

宝哥工具箱启动时会显示 Windows UAC 提示，必须通过管理员授权后才能进入主界面。文件解除占用、ETW 网络监控和上传限速因此可以直接使用所需的系统权限；现有辅助进程仍负责隔离危险操作和网络采集生命周期。关闭工具箱时，网络辅助进程和 ETW 会话会一并退出。

启动入口在创建主窗口前显式申请管理员权限，取消授权则退出；从 EXE 或 `dotnet run` 启动主界面都必须通过管理员权限检查。

> 当前版本只限制上传速度，不限制下载速度。完整的双向限速需要安装网络过滤驱动，已在架构中预留扩展接口，但本版本不安装驱动。系统进程或受保护进程可能无法读取程序路径，此类进程仍会显示流量，但不能设置限速。

## 下班倒计时

- 输入当天上班时间，支持半角冒号 `08:30`、全角冒号 `08：30` 或四位数字 `0830`，也可点击“使用当前时间”填入当前小时和分钟，再点击“开始 / 重新计算”。成功开始后统一显示并保存为 `HH:mm`。所有日期禁止早于 07:30；可以提前填入今天尚未到达的上班时间，页面会标明尚未上班。
- 工作日 / 调休补班日：07:30—09:30（含）上班，正常下班时间为上班时间加 9 小时，已含午休；晚于 09:30 标记“今日迟到”，正常下班仍固定 18:30。
- 工作日加班可为 0（不加班），否则须为整数且至少 2 小时；周末、节假日全天算加班，整数且至少 4 小时。
- 加班扣除实际经过的午休 12:00—13:00、晚饭 19:00—19:30；未跨过的休息不扣除，恰好结束于休息开始时不顺延。支持跨午夜，后续每天仍扣除相同休息窗口。
- 显示正常下班、预计下班、加班内休息扣除、迟到状态和秒级倒计时。倒计时表示真实距离下班的时间，吃饭时仍继续倒数；切换工具不中断，休眠恢复后按系统时间重新计算。
- 到达最终预计下班时间后（包括设置的计划加班），面板显示“你已无偿加班”，大时钟从 `00:00:00` 开始累计超出时间，超过 24 小时不归零。这是对超出计划时间的趣味提示，不判断实际出勤或薪酬。
- 到点弹出一次不抢焦点的置顶提醒，切换其他工具、主窗口最小化仍可提醒；关闭提示不停止计时。每个任务在本次运行只提醒一次，时钟回拨和相同任务重复计算不重复提醒；重置或开始不同任务后重新计，重启恢复当日已到点任务会补提醒一次。退出工具箱后不运行后台提醒。
- 提醒采用蓝底白字的“即将关机”警告样式，正文为“你已经下班，我要把你电脑关了”，保留“关闭”按钮及超时计时，不显示解释性小字。该外观只是趣味提醒，不调用系统关机、注销或进程结束操作，也不锁定屏幕。
- 点击“下班”结束本次计时，关闭已有的到点警告且不再触发后续警告；弹一次结果提示，并在面板保留同样的结果、实际下班时间和已停止的计时数值。工作日早于正常下班时间才提示早退及提前分钟数；正常或超时下班提示“已下班，抓紧回家吧！”。未完成计划加班单独提示，不将其作为早退依据；周末、节假日仅判断计划加班是否完成。
- 未开始计时、尚未到上班时间或已经下班时，“下班”按钮不可用。结束状态与任务一起保存，同一任务日期重开仍保持停止且不补弹结果；保存失败会告警，本次仍保持停止。点击“开始 / 重新计算”可重新计时，“重置”清空结果；无效输入不会破坏已结束状态。
- 有加班时，倒计时卡片额外显示计划加班净时长、带日期的加班起止时间，以及按时长变化的趣味提醒。工作日加班达到 15 小时、周末 / 节假日达到 22 小时时显示超长加班吐槽，仅提醒，不拦截计时；文案不是健康或考勤上限标准。无加班或重置后隐藏，尚未应用的输入不影响当前任务卡片。
- 内置中国大陆 **2026 年**节假日和调休补班日，离线自动识别；来源为[国务院办公厅通知](https://www.beijing.gov.cn/fuwu/bmfw/sy/jrts/202511/t20251104_4258838.html)。允许手动覆盖，公司安排以自行选择为准。其他年份明确提示缺少日历，必须手动选择类型，不会猜测未来调休。
- 修改输入后，需要点击“开始 / 重新计算”应用；修改错误不会覆盖正在计时的任务。跨午夜运行中的任务保持原目标，新开始的任务采用当天日期。
- 本地时间及日期以 Windows 系统设置为准。记录保存在当前用户 `%LOCALAPPDATA%\ToolsBox\work-countdown.json`，只包含任务日期、上班时间、日期类型、计划加班时长及可选的实际下班时间；同一任务日期重开可恢复，旧日期不自动启动。重置会删除记录；保存 / 恢复失败有明确提示，不影响其他工具。

### 钉钉打卡提醒（可选）

- 工具箱主窗口和普通权限打卡提醒分别单实例；再次打开新版工具箱会唤起已有主窗口。首次从旧版升级请先退出旧主窗口和托盘提醒，旧版不支持新版的实例协议。
- “自动识别”会把唯一的钉钉账号数据目录显示到输入框，多账号时提示手动选择，不自动猜测。“保存设置”用于保存该目录和仅今天有效的工作日 / 休息日选择。
- 点击“我已打卡”后显示“已打卡（手动确认）”并禁用按钮；读取到今日打卡则显示“已打卡（已识别）”并禁用按钮。次日按新一天状态恢复。

- 默认关闭。在下班倒计时中勾选并确认后，开启本地打卡读取和当前 Windows 用户登录自启；取消勾选会撤销本功能自启项。请将 EXE 放在固定位置，移动后重新启用。
- 工作日（含调休）07:30—09:30 在电脑处于活动、未锁屏状态时读取，登录、解锁、唤醒触发检查，并以 5 分钟轮询兜底。09:25 是最后一次提醒，之后不补弹。支持手动设置仅今天为工作日或休息日；内置节假日日历仅支持 2026 年。
- 未确认打卡时显示可关闭的置顶提醒，可点击“我已打卡”停止当天提醒；手动确认不会生成打卡时间。读取到今日真实上班记录后自动导入倒计时，已有任务或手动输入存在冲突会先询问，已结束的任务不会自动恢复。
- 自动定位当前用户钉钉数据及重定向目录；多账号不猜测，请选择自己的账号数据目录（不是程序安装目录）。读取失败只表示“尚未确认”，请在钉钉核对，不代表未打卡。
- 仅在内存中解析本地快照，不修改钉钉原库、不上传消息、不保存聊天明文。功能状态保存于 `%LOCALAPPDATA%\ToolsBox\attendance`。登录自启打开完整工具箱主窗口，需确认 Windows 管理员授权，然后启动普通权限打卡后台；拒绝授权则本次不启动。不支持由另一个管理员账号代为开启。旧版仅后台启动项需取消勾选后重新启用；Windows 禁用状态需在系统启动设置中处理。
- “立即检查”全天可用，即使今日已点“我已打卡”或设置为休息日，也能手动读取。显示请求中、检查结果或超时提示；不会清除手动确认，也不会因手动检查额外弹出打卡提醒。需先启用功能并同意本地读取。
- 已在本机 2026-09-22 只读验证到 07:50 的上班记录；这不保证其他钉钉版本兼容，也不替代企业正式考勤。实际重启登录、锁屏/休眠恢复仍需在启用后验证。

### 下班操作示例

工作日 09:30 上班、计划加班 2 小时：正常下班为 18:30，加班扣除 19:00—19:30 晚饭时间，预计下班为 21:00。

| 点击“下班”的时间 | 面板及弹窗结果 |
| --- | --- |
| 18:00 | 提示早退 30 分钟，另提示计划加班未完成 |
| 18:30 | “已下班，抓紧回家吧！”，另提示计划加班未完成，不算早退 |
| 21:15 | “已下班，抓紧回家吧！”，超出计时停在 00:15:00 |

点击后计时停止，同一任务日期重新打开仍保留结束状态，不再弹出到点提醒。要开始新的计时，请点击“开始 / 重新计算”。

## 构建与测试

### 一键打包（推荐）

项目根目录提供两个可双击的执行文件，也可从 PowerShell 或 CMD 调用。打包电脑需要安装可构建 .NET 8 项目的 **.NET SDK**（只有 Runtime 不够）；首次打包或缺少依赖缓存时需要联网还原 NuGet 包。无需为打包而以管理员身份运行。

| 入口文件 | 生成版本 | 输出位置 |
| --- | --- | --- |
| `Publish-SelfContained.cmd` | 内置 .NET，使用者无需另装 .NET 运行环境 | `bin/publish/self-contained-win-x64/<时间戳唯一标识>/宝哥工具箱.exe` |
| `Publish-FrameworkDependent.cmd` | 不内置 .NET，使用者需要 .NET 8 Desktop Runtime x64 | `bin/publish/framework-dependent-win-x64/<时间戳唯一标识>/宝哥工具箱.exe` |

双击后显示构建过程和最终 EXE 的完整路径、大小，结束时等待按 Enter，方便查看错误。终端或自动化调用时使用 `-NoPause`，执行完立即退出并返回成功（0）或失败（非 0）状态：

```powershell
.\Publish-FrameworkDependent.cmd -NoPause
.\Publish-SelfContained.cmd -NoPause
```

可以从其他工作目录用完整路径调用，例如 PowerShell：

```powershell
& 'E:\work\ToolsBox\Publish-SelfContained.cmd' -NoPause
```

脚本自动定位项目，发布**当前工作区源码**，包括尚未提交的功能修改。两种模式均使用 Release、Windows x64、单文件配置；每次新建带时间戳的输出目录，不覆盖旧包、不清理历史目录、不关闭正在运行的工具箱。请顺序运行两个入口，同时打包会明确提示已有发布任务，避免共享构建中间文件发生冲突。

SDK 缺失时会提示官方下载地址；构建失败时保留控制台错误并返回失败，输出目录可能保留诊断或不完整文件，不能将其视为成功发布。确认日志显示成功及 EXE 完整路径后再分发。发布产物位于 Git 忽略的 `bin` 目录，不随源码提交。

两种版本功能一致，**均不捆绑视频下载组件和完整 WebView2 环境**；可在工具内进行环境检测与安装。打包不会添加激活、收费或数字签名。下列手动命令和 Visual Studio 发布配置仍可使用，但不包含一键入口的时间戳目录隔离及并发保护。

### 手动发布免安装单文件版（不带运行环境）

```powershell
dotnet publish .\src\ToolsBox.App\ToolsBox.App.csproj -c Release -p:PublishProfile=PortableWinX64
```

输出为 `bin\publish\win-x64\宝哥工具箱.exe`，具体体积随内置组件变化。Visual Studio 中也可选择 `PortableWinX64` 发布配置。发布版保留启动时的管理员权限要求。

双击 EXE 后，.NET 原生启动器会先检查兼容的运行环境：

- 环境齐全：直接启动工具箱。
- 缺少 .NET 或所需的 Windows Desktop Runtime：显示官方提示（可能为英文），提供下载入口；用户确认后打开微软下载页面，不自动安装。
- 手动下载入口：[.NET 8 官方下载页](https://dotnet.microsoft.com/zh-cn/download/dotnet/8.0)，选择 **.NET Desktop Runtime → Windows → x64**，安装完成后重新运行工具箱。运行发布版不需要安装 SDK。

该检查发生在 WPF/C# 代码执行前，不需要另加托管检测窗口。行为参考：[微软启动器说明](https://devblogs.microsoft.com/dotnet/dotnet-apphost-improvements/)。若电脑人为设置了 `DOTNET_DISABLE_GUI_ERRORS=1`，官方弹窗会被禁用；正常发布配置不会设置该变量。单文件依赖中的原生 DLL 会按 .NET 机制释放到用户临时目录，并非运行时完全不落盘。

### 手动发布免安装单文件版（内置 .NET）

```powershell
$publishOutput = Join-Path (Get-Location).Path 'bin\publish\self-contained-win-x64'
dotnet publish .\src\ToolsBox.App\ToolsBox.App.csproj -c Release -p:PublishProfile=PortableWinX64 -p:SelfContained=true -p:EnableCompressionInSingleFile=true "-p:PublishDir=$publishOutput"
```

请在仓库根目录运行上述命令，输出为 `bin\publish\self-contained-win-x64\宝哥工具箱.exe`。发布产物位于 Git 忽略的 `bin` 目录，不随源码提交。

### 自动化检查

日常回归使用以下安全筛选命令，排除会实际关闭辅助进程文件句柄的测试：

```powershell
dotnet test .\ToolsBox.slnx --configuration Release --filter 'FullyQualifiedName!=ToolsBox.App.Tests.Startup.SystemHandleScannerTests.CloseHandleAsync_ReleasesChildProcessFileHandleWithoutEndingProcess'
dotnet build .\ToolsBox.slnx --configuration Release --no-restore
```

被排除的 `CloseHandleAsync_ReleasesChildProcessFileHandleWithoutEndingProcess` 仅应在确认风险后的隔离测试环境中单独运行；不要将不带筛选的全量测试作为日常检查。自动化通过不代表已验证最终 EXE 的 UAC、真实弹窗、最小化提醒及休眠恢复。

网络辅助进程的实际运行验证需单独执行（Windows，可能显示 UAC 提示）：

```powershell
dotnet run --project .\tests\ToolsBox.NetworkSmoke --configuration Release -- "E:\work\ToolsBox\src\ToolsBox.App\bin\Release\net8.0-windows\宝哥工具箱.exe"
```

请将最后的路径替换为实际构建的程序路径。该验证检查辅助进程不打开主窗口、两轮 ETW 回环 UDP 流量采集与停止重启、读取 QoS 规则以及正常退出；不会新增或修改限速规则。

可在管理员 PowerShell 中验证发布版的缺失环境错误路径：

```powershell
.\scripts\Test-MissingRuntime.ps1 -ExecutablePath .\bin\publish\win-x64\宝哥工具箱.exe
```

脚本只为测试子进程指定隔离的运行时目录，不卸载现有 .NET，不修改全局环境变量。为避免自动化被对话框阻塞，仅在测试子进程中禁用 GUI 提示并检查错误码、缺失框架名称和官方下载链接；这不代替干净 Windows 机器上的弹窗与下载按钮人工验收。

## 项目结构

- `src/ToolsBox.Core`：端口模型与刷新协调、文件操作安全规则、下班时间计算与节假日日历。
- `src/ToolsBox.Windows`：Windows IP Helper API、系统句柄扫描、ETW 网络采集、提权 IPC 和 QoS 管理实现。
- `src/ToolsBox.App`：WPF 工具箱外壳、工具界面及普通权限网页工作模式、下班提醒与本地计时状态保存。
- `src/ToolsBox.MediaDownloads`：组件安装校验、网站视频解析、图片下载、MP4 合并转码和输出验证。
- `tests`：领域规则、进程操作安全、状态恢复、WPF 控件集成测试及独立网络冒烟验证。

新增工具时应保留独立的领域/平台边界，并在 `ToolsBox.App` 中增加对应导航和视图。
